## Giới thiệu
Ứng dụng React xem thời tiết 8 thành phố Việt Nam, sử dụng dữ liệu trực tiếp từ API miễn phí Open-Meteo (không cần API key).

## Danh sách yêu cầu đã hoàn thành
- [x] **YC1:** Danh sách 8 thành phố Việt Nam, làm nổi bật thành phố đang chọn.
- [x] **YC2:** Hiển thị thời tiết hiện tại: biểu tượng, mô tả tiếng Việt, nhiệt độ, độ ẩm, tốc độ gió, thời điểm cập nhật.
- [x] **YC3:** Dự báo 7 ngày: thứ, ngày, biểu tượng, nhiệt độ cao nhất (°max) và thấp nhất (°min).
- [x] **YC4:** Hiển thị đầy đủ các trạng thái: chưa chọn, đang tải (loading spinner), báo lỗi (kèm nút Thử lại).
- [x] **YC5:** Đổi nhiệt độ °C / °F tức thì (chuyển đổi trên giao diện, không gọi lại API).
- [x] **YC6:** Giao diện Responsive (màn hình từ 768px hiển thị 2 cột; nhỏ hơn tự động xếp dọc).
- [x] **Nâng cao:** 
  - Tìm kiếm thành phố không phân biệt dấu tiếng Việt.
  - Đánh dấu thành phố yêu thích lưu vào `localStorage`.
  - Tự động đổi màu nền theo tình hình thời tiết.
